# WilliCat Hybrid Café Kit DEV

Open `Open_Hybrid_Cafe_Kit.command` to prepare/import/run a fresh isolated project. Requires installed Blender 5.2.1 LTS for rebuilding, Godot 4.7.2 for review, and existing Forge Python Pillow/NumPy environment (launcher selects it when necessary).

Click floor to walk. **Depth Walk** runs the real navigation tour; **Make Coffee** runs the original service loop; **2D Baseline** reveals the retained approved source. Camera is fixed; there is no free rotation.

The source repository must remain intact for approval binding and gameplay assembly. Temporary import/cache/save files belong to the isolated project/DEV namespace. This launcher never publishes or migrates Home.

Builders generate editable sources and GLBs into an explicit output directory. See `docs/architecture/WILLICAT_HYBRID_3D_ASSET_PIPELINE_V1.md` for axes, semantic origins, shared material mapping and evidence. Provider adapters, Factory approval authentication and production publication are outside this tool.
