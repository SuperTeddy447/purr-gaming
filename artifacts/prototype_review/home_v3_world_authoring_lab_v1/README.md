# Home V3 World Authoring Lab viewport evidence

All images below are unfiltered full-viewport PNGs rendered by Godot 4.7.2 from the isolated dev scene. `F6` in the running lab regenerates the pack. These are layout/contract evidence, **not** final art or production Home captures. The first eight files use the live editor game viewport (539×959); the last two use a second Godot `SubViewport` (539×1168) instantiating the same lab. Debug overlay is off except image 02. The underlying lab runs its semantic proof in automatic development mode; it is not the production café loop.

The 9:16 editor viewport scene camera is zoom 1.8 in project logical coordinates (effective physical world scale ~0.84); tall SubViewport is zoom 0.84. The camera director temporarily changes position/zoom during shots and restores them. In images 01 and 08 the top HUD bar and bottom margin do not cover essential slot centers. Greybox labels are small, so final interaction readability and touch comfort require human review. In the Cat Emotion shot the cat remains toward the left of frame because the camera obeys its world limits; assess that composition before art. No art or UI polish was performed to hide these issues.
