## Key proof and limits

The table's blocked rectangle is 108×80 floor units, not its illustrated size. The real nav path from `(75,455)` to `(445,455)` bends around it, including waypoints below the table; sampled actor feet never enter the footprint. A direct line would pass through it. Room rebakes after moving Espresso, Chair, Bed, Plant, and event display. The lab uses one region and a small number of objects, so this is architectural correctness, **not** a mobile performance benchmark or a multi-room streaming solution.

Static authored architecture should be placed in `.tscn` and baked once. Potentially movable furniture keeps a stable instance ID, object-local footprint/slots, a placement validator, and a serializable transform snapshot. An optional invisible placement grid may be introduced only if decorating needs snapping/occupancy; it must not impose a visible tile aesthetic on illustrated rooms. The current freeform model works without it.

## Mobile cost review

| System | Expected risk | Production measurement/guardrail |
| --- | --- | --- |
| NavigationAgent2D × customers/cats | Per-physics path queries and movement; dense crowds add collision/avoidance work. | Keep agent count bounded; profile path queries and physics on the lowest device. Add avoidance only after crowd QA shows a need. |
| Runtime nav rebake | Polygon generation and server synchronization can spike if every furniture drag rebakes. | Bake fixed room once; debounce validated discrete placements and measure worst-case room size. Never rebake each drag frame. |
| Slot discovery | Lab recursive tree walk is O(objects × slots) per request. | Room-scoped action/ID registry with registration/invalidation for spawned/removed objects; request only on action decisions, not each frame. |
| Reservation registry | Small dictionaries/weakrefs and local signals; low cost, but stale references are correctness risk. | Assert cleanup on actor/object/room teardown and track active reservations in debug builds. |
| CameraDirector | One short Tween and target follow each shot; small cost. | One camera owner per room; kill interrupted tweens and avoid layered competing animations. |
| EventLayer and visual objects | Hidden nodes may retain collision/nav processing if merely invisible; draw and memory can grow with assets. | Toggle semantic/nav contribution explicitly; stream large event scenes and profile memory/import sizes. |

The six-actor lab is intentionally too small to establish a shipping device budget. Performance must be measured during the staged Home migration, not inferred from this desktop result.
