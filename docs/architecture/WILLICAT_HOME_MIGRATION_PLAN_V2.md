# Home migration plan V2 — proposal, not authorization

**No Home scene or True Vertical Slice migration occurred in the hardening task.** The currently playable Home remains the comparison baseline. This order replaces the [draft V1](WILLICAT_HOME_MIGRATION_PLAN_DRAFT_V1.md) only after human architecture review.

1. **Freeze parity evidence.** Record 17 stable asset IDs, current Home camera/aspect profiles, routes, seat A–D assignments, CoffeeAction/Serve/Order semantics, debug controls, pan/tap behavior, occlusion and existing automated tests. Preserve a runnable old scene and capture pack.
2. **Introduce room-scoped semantic registry behind an adapter.** Register existing global markers under stable IDs without moving art or rewriting the loop. Support duplicate roles, capacity, invalidation, dynamic spawn/remove and diagnostics. Test old code path and adapter parity.
3. **Author a CounterServiceZone in an isolated candidate Home.** Keep CounterShell's customer-facing OrderPoint/ServePoint/front occluder. Instance EspressoStation separately with CoffeeAction, steam/cup and camera anchors. Move equipment in Editor to prove ownership, then compare counter depth.
4. **Bridge InteractionSlot/reservation into the existing True Slice.** Keep current customer/worker business states, rewards and timing as source of truth; use slots only for semantic destination/occupancy at first. Prove cancellation, restart, reward-once, manual/auto parity.
5. **Convert seating one chair/table at a time.** Preserve seat A–D stable identity and table layout. Owned seat/approach/exit markers and physical footprints replace detached global coordinates only after each route succeeds.
6. **Convert entrance/exit and cat-life objects.** Entrance owns threshold and door semantics; room owns transition destination. Beds/plants/baskets own their local slots and footprints. Keep ambient policies separate from pathfinder.
7. **Author walkable geometry around real footprints.** Bake fixed architecture and furniture; establish a debounced movement/rebake policy. Test table/counter/entrance routes, moving-object target refresh, multi-agent congestion and phone frame budget.
8. **Revalidate depth.** Foot-pivot Y-sort, counter back/front split, table/chair/plant/entrance foreground and carried cup must match the baseline. Never patch actor z-index by state.
9. **Integrate CameraDirector by adapting the existing CameraRig.** Do not replace approved portrait framing. Add object-owned Brew/Cup/Emotion/Event anchors, shot priority/cancel, exact pan/zoom restore, HUD policy and safe-area tests for 9:16 and tall phone.
10. **Add event-compatibility hooks.** Room-scoped EventLayer must gate visual, slot and nav contribution; one base-room variant and one separate event room should reuse actor scripts before content production.
11. **Run full True Slice parity and visual/runtime review.** Automated manual/auto/reward tests, Godot parser scan, repeated-loop stability, device captures, GodotAI Editor object-move proof, and mobile profiling. Compare to old Home without retouching Visual Master/art to conceal structural issues.
12. **Human cutover decision.** Switch the default Home only after design/engineering sign-off on route feel, readability, camera composition and performance. Retain the old runnable baseline and a reversible feature switch until release confidence is established.

At each stage, stop if a locked visual/layout or gameplay result changes unexpectedly. Prefer narrow adapters and side-by-side evidence to a large scene rewrite. Remaining open design choices: save schema/versioning, whether decorating warrants an invisible snap grid, dynamic nav rebake frequency, queue/avoidance policy for dense multi-agent café play, and specific device camera safe-area tuning.
