## Human approval and mobile cutover gate

Review at default 540×960 plus tall portrait, not only a zoomed close-up. Pass character only if orange fur, cream muzzle, eyes, markings and silhouette remain legible in day/sunset/night/rain **at fixed scale**. Pass materials only if wood/plaster/jade/brass/glass remain recognizably WilliCat under each state without flatness or over-saturation. Pass lamp if OFF fixture looks credible, ON lights nearby actual art, DIMMED is distinct and no baked glow remains when OFF. Pass window if the same frame supports four moods with independent exterior/rain and no permanent beam. Pass shadow if cat/chair are grounded softly and moving chair leaves no painted stain. Reject normal maps if they distort matte form. Reject any baked-lighting conflict, non-transparent source, style mismatch or layout/occlusion pressure.

Mobile is a separate release gate: on at least one target low/mid-tier phone, record renderer/device, 9:16 and tall viewport, p50/p95 frame time and FPS over ≥10 minutes, memory, thermal/battery, active PointLight2D count, shadow-enabled light count, occluders, weather particle count, full-screen shader cost (baseline should be zero) and optional normal-map delta. The desktop prep/capture does **not** certify phone performance or final visual production.
