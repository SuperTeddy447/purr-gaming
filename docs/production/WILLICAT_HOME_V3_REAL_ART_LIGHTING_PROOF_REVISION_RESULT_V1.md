# Home V3 real-art lighting proof revision V1 — micro-room result

Status: **PASS / FINAL VISUAL PRODUCTION GATE READY**, limited to the controlled real-art lighting/compositing proof. It does **not** approve final Home art, migrate production Home, or certify a phone frame-time budget. [Rendered evidence](../../artifacts/prototype_review/home_v3_real_art_lighting_proof_revision_v1/README.md) is the review authority; the earlier [V1 failure](WILLICAT_HOME_V3_REAL_ART_LIGHTING_PROOF_RESULT_V1.md) remains preserved rather than rewritten.

## Scope and registration

The new [revision scene](../../scenes/dev/home_v3_real_art_lighting_proof_revision_v1.tscn) inherits the original dev proof. It repositions **only its own presentation nodes** into a service-wall micro-room: architecture wall/floor plate, wall-mounted lamp, inset-looking window/exterior card, chair and unchanged cutout on one floor. The inherited base scene retains its original coordinates and 15-shot pack. No locked Home V3 or gameplay root moved. The approved five PNGs are the **same texture resources** in both scenes; no new image generation, repaint, crop, normal-map source or protagonist identity edit occurred.

The 1400×920 / 256×768 / 256×320 / 320×320 / 512×512 texture canvases remain import contracts, **not world-unit sizes**. The locked [Home V3 handoff](WILLICAT_HOME_V3_ART_HANDOFF_SPEC_LOCK_V1.md) supplies relative scale, especially chair 0.30–0.45 of character height; the dev scene sets independent uniform `world_scale` values. Room camera is 540×960 portrait at zoom 2.7. Approximate alpha>16 visible dimensions and scene registration:

| Sample | Dev root | Uniform display scale | Approx. world-visible size / ratio |
| --- | --- | ---: | --- |
| Architecture | `(320,500)` | 0.55 | 619×407 world units; service-wall/floor bay |
| Window | `(495,330)` | 0.32 | 71×213; about 1.81× standing cat height |
| Practical lamp | `(235,310)` | 0.34 | 51×51; mounted above the wood rail on cream wall |
| Chair | `(420,552)` | 0.23 | 39×43; **0.36× cat height** (inside locked band) |
| Orange protagonist | `(300,550)` | 0.32 | 122×118; approximately **149 px tall in the capture** |

The chair and cat feet are on the same illustrated floor, with owner-local contact shadows. Chair move is a temporary +52 world-pixel capture step, restored immediately. No texture was stretched non-uniformly or arbitrarily skewed to conceal a perspective mismatch. The approved window remains somewhat front-facing against the angled wall; this is acceptable as a **lighting-sample vignette**, not a final fitted Home V3 window installation.

This does not block the primary atmosphere/compositing proof.

## Limits and validation

The architecture sample is a landscape rectangular plate; the portrait screenshots necessarily show neutral mat above and below the central bay. The real-art bay is nevertheless the main evaluation region (about 515 of 960 vertical pixels), and the neutral mat is not used to judge material response. The front-facing proof window will need authored fitting/recess detail when production Home art is actually composed; no individual approved source is rejected by this micro-room test. The window card is a dev-only shape, not a generated exterior asset. There are 2 local `PointLight2D` nodes, 0 shadow-enabled lights, 0 occluders, 0 weather particles, 0 normal maps, and 1 world `CanvasModulate`; HUD is isolated on `CanvasLayer`.

The 16 captures came from Godot 4.7.2's Metal Mobile renderer on Apple M2 Pro, each a valid nonblank 540×960 PNG. A physical low/mid-tier phone performance and final asset-fit test are **still required** before shipping, including frame time, memory, thermals, tall-phone framing and rain/window readability. The original source PNG hashes and Godot-ready candidate PNGs were not changed by this revision. The capture guard was retained, and a revision test proves it rejects a missing candidate. Godot parser/runtime checks, focused tests and `git diff --check` were run; see the final task report for their exits. No commit or push.
