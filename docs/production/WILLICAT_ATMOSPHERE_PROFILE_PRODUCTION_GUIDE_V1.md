# Atmosphere profile authoring guide V1

This is a dev-lab workflow, not approval to migrate Home V3. The [catalog resource](../../scenes/dev/atmosphere/atmosphere_catalog.tres) is edited in Godot's Inspector as typed Resources. Use stable lowercase semantic IDs and review each axis separately. A location describes a **specific authored café environment** (latitude band, humidity/haze tendency, sky/contrast, window/exterior family, permitted seasons). It is not a country's flag color, architectural stereotype or actor rule. The four current country-labelled entries are reference scenarios only.

Add a season for daylight/foliage/exterior tendency; add time for ambient/direct/window/lamp curves; add weather as a modifier to direct/diffuse light, pane response and FX; add an event as a temporary tint/local-lamp/FX modifier. Do not make a separate room image for each Cartesian product. For smooth time flow, interpolate to a new `AtmosphereState` through the director rather than swapping scenes. Test unsupported season pairs: they must reject without changing the active state.

Review matrix: Japan-reference spring morning clear, Thailand-reference rainy-season afternoon rain, Europe-reference autumn evening cloudy, China-reference winter night clear; then hold location/season fixed for midday vs night, and location/time fixed for clear vs rain. Inspect [real viewport captures](../../artifacts/prototype_review/world_atmosphere_lighting_lab_v2/README.md), including debug images. Verify lamp OFF/ON/DIMMED, window rain, exterior difference, readable characters and independent HUD. F6 regenerates the pack when the lab scene is running; 4/5/6/7 switch the four matrix states, T day/night, Y clear/rain, L lamp override, G event, F7 existing debug. Existing F9/F10 world demo/event shortcuts remain in the inherited lab; do not confuse F10's gameplay display with G's lighting event.

For another room: instance/direct the same data/evaluator; author a CanvasModulate, subtle DirectionalLight2D, fixture-local lamps, window controller(s), contact shadows and independent CanvasLayer HUD; bind them via director exported NodePaths. Room-specific positions are set in the room scene only. Save semantic IDs/manual lamp override, not evaluated RGBA/energy. Verify in real viewport and on the cheapest supported phone before expanding to more local lights or shadow masks.

Mobile evidence table to fill before production: device/GPU, renderer, viewport, p50/p95 CPU+GPU frame time, battery/thermal after 10 min, memory, visible lights, shadowed lights, occluders, weather particle count, normal-mapped objects, transition hitch. No physical-device measurement was available for this lab; BASE/STANDARD/ENHANCED cost tiers in the architecture document are budgets to validate, not guarantees.
